# 最简笔记的优化说明

维护与产品优化：[@xliuweijie](https://github.com/xliuweijie)。开发过程中使用 Codex 协助实现。

上游来源：[usememos/memos](https://github.com/usememos/memos)，基线为 v0.31.0，提交 `2b2192d4e153bd04f1d325b60fd880cf00d68b01`。

## 1. 让编辑器更专注于写与保存

`web/src/components/MemoEditor/` 的编辑面板收起格式工具栏、插入菜单、录音界面、时间调整等高级控件。正文区的留白、内边距和圆角做了调整；底部只显示保存、按场景出现的取消、以及当前可见范围。

保存动作继续使用已有校验和保存流程：未满足条件时禁用，保存过程中显示等待状态，完成后显示已保存状态。可见范围沿用已有设置，不把「简化界面」解释为更改笔记的访问权限。

聚焦编辑仍保留关闭入口；Markdown 编辑和快捷键继续使用现有实现。粘贴文件进入附件列表，拖入图片仍可在拖放位置内联插入。原有格式、录音等组件源码保留，但不再由当前编辑器挂载。

## 2. 收拢侧边栏

`web/src/components/AppSidebar/AppSidebar.tsx` 将主要导航收敛为「笔记」「搜索」「归档」，保留写笔记入口与用户菜单。主页侧栏中的统计、标签区与多层导航被收起；日历、地图、附件等高级功能不再占用主要导航。

这是前端入口和布局的调整。相应页面、后端能力以及已有数据仍保留在仓库中；本版本没有声称移除上游的全部高级功能。

## 3. 统一名称、图标和默认文案

新增 `web/src/lib/branding.ts` 管理「最简笔记」名称、说明和图标默认值，覆盖浏览器标题、应用 Logo、登录页、关于页、实例设置、恢复默认配置和 Web App Manifest。

默认名称与上游默认标识会映射到本项目品牌；用户明确设置的非默认名称和 Logo 继续保留。图标为新增的 `web/public/note-logo.svg`。

中文文案调整为「笔记」「写笔记」「写下此刻的想法」；涉及品牌名称的英文文案同步更新。

## 4. 验证与范围

新增或更新了品牌默认值、侧栏导航与标识、极简编辑工具栏、语言资源及相关编辑器行为的测试。2026-10-28 发布前验证：`pnpm lint` 通过（检查 675 个文件）；`pnpm test` 通过（182 个测试文件、1,523 项测试）；`pnpm build` 通过。生产构建仍有上游 CSS `::highlight` 解析与大体积 chunk 提示。

本次没有修改后端 Go 服务、数据库模式或认证协议。当前环境没有 Go 与 Docker，因此没有重新运行 Go 测试或实测自建 Docker 镜像。Docker 文档使用仓库现有 Dockerfile，并要求先通过 `pnpm release` 构建本项目的前端。

## 5. 继续改进

欢迎围绕写作专注度、移动端体验、可访问性和清晰文案继续优化。涉及共享、权限和数据迁移的改动应保持行为明确。具有通用价值的改动，也欢迎在充分验证后向上游提出贡献。

感谢所有让这个项目成为可能的开源作者与贡献者。
