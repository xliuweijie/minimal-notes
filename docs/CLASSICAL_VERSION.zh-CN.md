# 古典版发布说明

产品优化与维护：[@xliuweijie](https://github.com/xliuweijie)，使用 Codex 协助实现与验证。

上游：[usememos/memos](https://github.com/usememos/memos) v0.31.0。本次应用代码来自本机 `restore-eff66ff` 分支的 `d77c548`「古典版本」；本文和 README 为随后补充的发布文档。

## 视觉变化

- 浅色界面改为暖米色纸面、深棕色文字，以朱砂色突出按钮、链接和输入聚焦状态。
- 标题、侧栏标签、笔记正文、编辑区域改用宋体风格字体栈，包含 Songti SC、Noto Serif CJK SC、Source Han Serif SC、SimSun 等系统回退字体。字体效果取决于设备已有字体；没有额外安装或下载字体。
- 编辑区正文行距改为 1.8，增强连续书写和阅读的空间感。代码块继续使用等宽字体。
- 页面与侧栏添加由 CSS 生成的轻微纸纹，侧栏头部和底部使用双线分隔，卡片和编辑区域添加轻薄纸页阴影。
- 深色模式同步使用暖墨色背景、暖铜色强调和纸质感边框。

## 表情入口的变化

- 移除笔记卡片顶部的新增表情按钮。
- 移除已有表情列表旁的新增入口和弹出选择面板。
- 删除已不再使用的 `ReactionSelector.tsx` 和原选择器测试，新增表情列表行为测试。
- 正文中的 emoji、历史表情数据，以及已有表情的显示与现有交互继续保留；没有清理或迁移个人数据库。

## 与上一公开版的差异

此前公开版来自 `codex-vibe-demo` 分支，包含 `1403417`「左侧也修改」和 `91498a9` 的开源说明。

古典版是在恢复 `eff66ff`「简化编辑器」后新建的分支上继续完成的。因此：

- 简化编辑器和「最简笔记」品牌仍保留。
- 侧栏采用 `eff66ff` 的较完整布局，而非此前公开版收拢后的「笔记／搜索／归档」导航。
- 当前发布新增古典样式和移除表情新增入口的改动。
- 原先的开源致谢、MIT 许可证与优化说明作为文档保留；历史极简版优化记录已标注适用版本。

GitHub 更新采用新的提交来保存这次完整状态，旧提交仍可查看，不重写已经公开的历史。
